# KeyFrame – Rhythm Game & Piano Simulator

KeyFrame is a rhythm game that combines piano-style play with timing challenges. Hit the right notes at the right moment to build combos and improve your score. It runs entirely in the browser with no installation needed.

## Features
- Piano-style gameplay
- Rhythm challenges with timed note cues
- Scoring and accuracy feedback *(confirm)*
- Multiple songs or levels *(confirm)*

## Getting Started
1. Clone the repo:
   ```
   git clone https://github.com/Hugo-Code21/KeyFrame-RhythmGame.git
   ```
2. Open the `Games` folder
3. Open the game's `.html` file in your browser *(add the exact filename)*
